# LeetCode 刷题区

本仓库是我个人的 LeetCode 刷题记录区，按题单分类存放每日刷题代码。

## 目录结构

```
leetcode/
├── src/
│   ├── random/          # 每日一题解答（a<题号>.java）
│   ├── 常用数据结构/    # 题单分类：差分 / 堆 / 队列 / 枚举技巧 / 前缀和 / 栈
│   │   └── 枚举技巧/    #   枚举中间 / 枚举右维护左
│   ├── 二分查找/        # 题单分类：二分查找
│   ├── 单调栈/          # 题单分类：单调栈
│   ├── 滑窗/            # 题单分类：滑动窗口（不定长滑窗 / 定长滑窗）
│   └── 网格图/      # 题单分类：网格图
└── .gitignore
```

> `src/out/` 为编译输出目录，已被 `.gitignore` 忽略，不入库。

## 文件命名约定

- 题目解答：`a<题号>.java`，其中 `<题号>` 为题目在 LeetCode 上的编号。
  例如 `src/二分查找/a704.java` 对应 LeetCode 704 题，`src/random/a3310.java` 对应 LeetCode 3310 题。
- `_banzi.java`：对应分类的**模板代码**（如二分查找模板），不是题目解答。
- `说明`（无扩展名）：对应分类的**知识点笔记**（如 `常用数据结构/堆/说明` 记录堆的相关知识）。

## 题单来源

`src/` 下各分类目录对应题目来源于**灵茶山艾府**的「[分享｜如何科学刷题？](https://leetcode.cn/discuss/post/3141566/ru-he-ke-xue-shua-ti-by-endlesscheng-q3yd/)」题单，每个分类目录即题单中的一个主题。

## 每日一题

`src/random/` 存放每日一题的解答，命名同样为 `a<题号>.java`。
